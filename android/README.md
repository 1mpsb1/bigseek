# BigSeek для Android

Мобильная версия BigSeek в том же стиле: AMOLED-интерфейс, изолированные сессии,
счётчик токенов, распознавание лимитов и автоперенос контекста.

![Главный экран](../docs/android-main.png)

## Как устроена изоляция

Android WebView хранит cookies и localStorage в одном каталоге на процесс. Поэтому
каждая сессия запускается в **отдельном процессе** (`:s1` … `:s6`) и перед созданием
WebView вызывает `WebView.setDataDirectorySuffix("sN")`. В результате у каждой сессии
свой каталог `app_webview_sN` — свои cookies, localStorage, IndexedDB и кэш.
Максимум — 6 сессий (по одной на слот).

Список сессий и их состояние лежат в `files/sessions.json`; чат-процессы обновляют
свою запись атомарной перезаписью файла.

## Сборка

Нужны Android SDK (build-tools + платформа) и JDK. Проще всего — установленный
Android Studio: его `jbr` и SDK подхватываются автоматически. Gradle не используется,
APK собирается напрямую: `aapt2` → `javac` → `d8` → `zipalign` → `apksigner`.

```bat
android\build.bat                     :: только APK
android\build.bat -Install -Launch    :: собрать, поставить на телефон и открыть
```

Или напрямую:

```powershell
powershell -ExecutionPolicy Bypass -File android\build_apk.ps1 -Install -Launch
```

Готовый файл: `android\build\BigSeek.apk`.

Подпись: `android\keystore\bigseek.jks` создаётся при первой сборке (в git не попадает).
Если собрать APK на другой машине, подпись будет другой — перед установкой удалите
старую версию (`adb uninstall com.bigseek.app`).

## Установка на телефон

```bat
adb install -r android\build\BigSeek.apk
```

Через `adb` установка идёт без запроса «Разрешить установку из неизвестных источников».
Если ставить APK вручную через файловый менеджер, разрешите ему установку приложений
в настройках Android.

## Возможности

- **Сессии.** Карточки со статусом, объёмом контекста (`112K/128K`) и прогрессом.
  Долгое нажатие — переименование, сброс счётчика токенов, сброс статуса, очистка
  данных сайта, удаление.
- **Чат.** Отдельный WebView на сессию, кнопка «назад» по истории, скачивание файлов.
- **Счётчик токенов** в шапке — фиксированной ширины, не дёргается. Считается объём
  переписки (≈2,5 символа на токен), а не число сообщений.
- **Лимиты.** Короткие сообщения сайта о квоте и HTTP 429 переводят сессию в
  «недоступна»/«ограничение»; время сброса («сброс в 03:00», «resets in 2 hours»)
  читается со страницы, и статус со счётчиком сбрасываются автоматически.
- **Автоперенос.** Из меню сессии: приложение отправляет промт сжатия, ждёт ответ,
  вырезает блок `===КОНСПЕКТ=== … ===КОНЕЦ===`, открывает **новый чат** в целевой
  сессии и отправляет туда конспект.
- **Настройки.** Домен, контекстное окно, порог предупреждения, период опроса,
  распознавание лимитов.

## Ограничения

- Вход через Google во встроенном WebView Google часто блокирует. Входите по e-mail
  и паролю; если аккаунт создавался через Google — задайте пароль через «Забыли пароль?».
- Скачивание файлов идёт через системный DownloadManager и может не получить cookies
  сессии; для защищённых ссылок файл может не скачаться.
- 6 сессий — это 6 процессов WebView. Если телефон начнёт нехватать памяти, Android
  сам выгрузит фоновые сессии; данные при этом сохраняются.

## Wi-Fi

Телефон подключён к `TP-Link_FE48_repeater` (сеть сохранена в системе). Если Wi-Fi
отвалится, включение Wi-Fi заново переподключит его автоматически:

```powershell
powershell -ExecutionPolicy Bypass -File android\keep_online.ps1
```
