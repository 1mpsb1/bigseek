# Как помочь проекту

Спасибо за интерес! Ниже — короткие правила, чтобы правки было легко проверять.

## Окружение

```bat
pip install -r requirements.txt
run.bat
```

Python 3.10+ (проверено на 3.14), PyQt6 и PyQt6-WebEngine.

## Что можно улучшить

- Распознавание лимитов и времени сброса на новых формулировках сайта
  (`app/web.py`, массив `PHRASES` и функция `findReset`).
- Устойчивость автопереноса к изменениям разметки DeepSeek (`app/transfer.py`,
  объект `DRIVER_JS`).
- Интерфейс, тема, доступность (`app/ui/`, `app/theme.py`).
- Документация и переводы.

## Правила

1. Одна логическая правка — один pull request.
2. Не добавляйте в репозиторий `dist/`, `build/`, `release/`, `data/` и чужие профили —
   они уже в `.gitignore`.
3. Проверьте, что приложение запускается: `python main.py`. Для UI-правок приложите
   скриншот.
4. Соблюдайте стиль кода вокруг: типизация, `from __future__ import annotations`,
   комментарии по-английски в коде, тексты интерфейса по-русски.
5. Для новой функции обновите `README.md`, а заметную правку — `CHANGELOG.md`.

## Сборка

```bat
build.bat     :: только exe
release.bat   :: exe + portable ZIP + установщик + SHA256
```

Установщик требует [Inno Setup 6.3+ / 7.x](https://jrsoftware.org/isdl.php).
