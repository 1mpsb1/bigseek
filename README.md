# BigSeek Desktop

Небольшой браузер-обёртка для **chat.deepseek.com**, где каждая сессия — это отдельный
профиль Chromium: свои cookies, localStorage, IndexedDB и кэш. В одной сессии — один
аккаунт, в другой — другой; они не пересекаются, как разные браузеры.

Интерфейс — AMOLED-тема: чистый чёрный фон, белый текст, серые акценты.

Автор: **1mpsb1**.

![Главное окно](docs/screenshot-main.png)

## Возможности

- **Изолированные сессии.** У каждой сессии собственный профиль браузера. Войдите в
  разных сессиях в разные аккаунты — они не мешают друг другу.
- **Панель сессий** перетаскивается за границу (200–560 px) и скрывается кнопкой `☰`
  или `Ctrl+B`; ширина и видимость запоминаются.
- **Настройки** (`Ctrl+,`):
  - домен/адрес сайта (если DeepSeek переедет — просто впишите новый);
  - открывать последнюю сессию при запуске;
  - загружать все сессии при запуске (быстрое переключение, но больше ОЗУ);
  - контекстное окно модели и порог предупреждения по объёму контекста;
  - частота проверки страницы;
  - включение/выключение распознавания лимитов.
- **Менеджер сессий** (`Ctrl+Shift+M`): переименование, переход, очистка данных сайта
  (выход из аккаунта), сброс счётчика токенов и статуса, удаление сессии, размер профиля
  на диске.
- **Адресная строка** и обычная навигация: назад/вперёд, обновить, на главную.
- **Скачивания** складываются в `profiles/<id>/downloads` и не смешиваются между сессиями.
- **Перенос контекста** между сессиями одной кнопкой (см. ниже).
- **Сброс счётчика токенов** — вручную (меню карточки, менеджер сессий, кнопка в баннере)
  или автоматически, когда наступает извлечённое со страницы время сброса лимита.

## Установка

### Вариант 1 — установщик (рекомендуется)

1. Откройте раздел **Releases** и скачайте `BigSeek-Desktop-<версия>-setup.exe`.
2. Запустите его. Установка идёт в профиль пользователя
   (`%LOCALAPPDATA%\Programs\BigSeek Desktop`), права администратора не нужны.
3. По желанию поставьте галочку «Создать значок на рабочем столе».

Установщик и программа пока не подписаны цифровой подписью, поэтому Windows SmartScreen
может показать «Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить
в любом случае»**. SHA-256 файлов лежит в `SHA256SUMS.txt` рядом с релизом.

Удаление — через «Параметры → Приложения → BigSeek Desktop» или ярлык в меню «Пуск».
Данные сессий при удалении **не** стираются: они лежат отдельно (см. раздел
[«Где хранятся данные»](#где-хранятся-данные)).

### Вариант 2 — портативная сборка

1. Скачайте `BigSeek-Desktop-<версия>-portable.zip` из **Releases**.
2. Распакуйте в любую папку. Запускайте `BigSeek Desktop\BigSeek Desktop.exe`.

Папку нужно хранить целиком: рядом с exe лежит `_internal` с QtWebEngine.
Чтобы данные (сессии, cookies, настройки) лежали внутри этой папки, создайте рядом
с exe пустой файл `portable.flag` — тогда используется подпапка `data`, а не
`%LOCALAPPDATA%`.

### Вариант 3 — из исходников

```bat
pip install -r requirements.txt
run.bat
```

или

```bat
python main.py
```

Требуется Python 3.10+ (проверено на 3.14) и PyQt6 с QtWebEngine. При первом запуске
создаётся сессия «Основная».

## Система лимитов

Лимит сессии — это не количество сообщений, а **объём контекста**. Одно длинное
сообщение может весить больше десяти коротких, поэтому BigSeek Desktop измеряет
переписку и оценивает токены (≈2,5 символа на токен), сравнивая их с контекстным окном
модели (по умолчанию 128 000 токенов, настраивается).

Источники сигналов:

1. **Объём контекста.** При каждом опросе страницы считается текст всех сообщений,
   результат виден в шапке (`52K/128K`) и на карточке сессии
   (`52K/128K · 12 сообщ.`). При достижении порога (по умолчанию 75%)
   появляется значок ⚠ и баннер с предложением перенести контекст.
   Считаются только настоящие сообщения чата: пока страница не догрузилась,
   показания не обновляются, поэтому счётчик не прыгает (`60K` → `30K`).
2. **Счётчик сообщений** остаётся только справочным: он показывает нагрузку за день,
   но больше не влияет на статус и предупреждения.
3. **Текст страницы.** Короткие сообщения сайта о квоте («достигнут лимит»,
   «reached the limit», «已达上限») переводят сессию в статус **«недоступна»**.
   Длинные ответы ассистента, где слово «лимит» лишь упоминается, не учитываются.
4. **Время сброса.** Если на странице написано, когда вернётся квота («сброс в 03:00»,
   «resets in 2 hours», «3 小时后重置»), приложение запоминает это время и само снимает
   статус «недоступна», как только оно наступит.
5. **HTTP 429.** Временное ограничение запросов — статус **«ограничение»**, обычно
   снимается сам через несколько минут.

Счётчик токенов сбрасывается автоматически вместе со статусом, когда наступает
извлечённое время сброса. Вручную его можно обнулить в любой момент: меню карточки
(«Сбросить счётчик токенов»), менеджер сессий или кнопка **«Сбросить счётчик»** в
баннере «Контекст подходит к концу». Счётчик обнуляется от текущего объёма переписки,
поэтому дальше он честно показывает только новые сообщения; если переписку очистили
или открыли новый чат, база сбрасывается сама.

Статусы:

| Статус | Как выглядит | Что делать |
|---|---|---|
| в норме | обычная карточка | работать |
| контекст почти заполнен | значок ⚠ без текста | сжать контекст и перенести |
| ограничение | серая рамка и мягкое свечение | подождать или перенести |
| недоступна | **красная рамка и свечение**, содержимое приглушено, значок «НЕДОСТУПНА» (на узкой панели — «ЛИМИТ»); войти в сессию всё равно можно | перенести контекст |
| перенесена | тусклая карточка | архив, можно вернуть статус |

У недоступной сессии в подписи видно время ожидаемого сброса (например, «сброс 03:00»),
а после наступления этого времени статус и счётчик токенов сбрасываются автоматически.

## Перенос контекста

Кнопка **«⇄ Перенос»** (или `Ctrl+T`) открывает мастер переноса. Всё происходит само:

1. Приложение отправляет в старую сессию промт сжатия и ждёт, пока ассистент допишет ответ.
2. Из ответа вырезается блок между строками `===КОНСПЕКТ===` и `===КОНЕЦ===`.
   Если модель забыла начальный маркер, конспект берётся из ответа перед `===КОНЕЦ===`,
   а если маркеров нет вообще — по заголовку «КОНСПЕКТ ДЛЯ НОВОЙ СЕССИИ». Обычный ответ
   без маркеров и заголовков конспектом не считается.
3. В целевой сессии **всегда открывается новый чат**, и конспект отправляется его первым
   сообщением — он никогда не дописывается в старую переписку.
4. Старая сессия по желанию помечается «перенесена», а готовая пара промтов остаётся
   в буфере обмена на случай сбоя.

Прогресс виден в полосе под панелью инструментов, там же кнопка отмены. Если обе сессии
не открыты или в одной из них нет входа, приложение скажет об этом. Ручной режим
(скопировать промты) остался в мастере под галочкой «Показать промты для ручного переноса».

Целевая сессия по умолчанию выбирается среди доступных с наименьшим объёмом контекста.
Если выбрать «＋ Создать новую сессию», приложение создаст её и сразу откроет в ней
новый чат.

## Где хранятся данные

По умолчанию: `%LOCALAPPDATA%\BigSeekDesktop`

- `sessions.json` — список сессий, статусы и счётчики;
- `settings.json` — настройки;
- `profiles/<id>/storage` — cookies и хранилище сайта;
- `profiles/<id>/cache` — кэш;
- `profiles/<id>/downloads` — скачанные файлы;
- `crash.log` — появляется только при падении.

**Портативный режим:** создайте рядом с exe (или `main.py`) пустой файл `portable.flag` —
данные будут лежать в папке `data` рядом с программой.

Очистка данных сессии удаляет только её профиль: остальные сессии и их аккаунты
не затрагиваются. Если часть файлов занята, остатки удалятся при следующем запуске
(папка `trash`).

## Сборка релиза

Всё собирается одной командой:

```bat
release.bat
```

или с явной версией:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1 -Version 1.2.1
```

Результат в папке `release` (в git не попадает):

| Файл | Что это |
|---|---|
| `BigSeek-Desktop-<версия>-setup.exe` | установщик (Inno Setup) |
| `BigSeek-Desktop-<версия>-portable.zip` | портативная сборка |
| `SHA256SUMS.txt` | контрольные суммы |

Что нужно для сборки:

- Python 3.10+ и `pip install -r requirements.txt`;
- [Inno Setup 6.3+ или 7.x](https://jrsoftware.org/isdl.php) — только для установщика.
  Если его нет, скрипт соберёт exe и ZIP и предупредит об этом.

Версия хранится в `version.txt` и подставляется в имя установщика и в свойства файла.

## CI и релизы

`.github/workflows/build.yml` собирает проект на `windows-latest` при каждом push,
а на теге вида `v1.2.1` дополнительно публикует GitHub Release с установщиком,
портативным ZIP и `SHA256SUMS.txt`.

```bat
git tag v1.2.1
git push origin v1.2.1
```

Сборка без тега доступна в разделе **Actions → build → Artifacts**.

## Ограничения

- **Вход через Google.** Встроенные браузеры Google иногда отклоняет с сообщением
  «этот браузер или приложение может быть небезопасным». BigSeek Desktop маскируется
  под обычный Chrome (User-Agent и client hints `sec-ch-ua*`), но гарантий нет: Google
  может менять правила. Если вход через Google всё равно не проходит — войдите
  по e-mail и паролю. Если аккаунт создавался только через Google, задайте пароль:
  на странице входа нажмите «Забыли пароль?» и восстановите доступ на почту Gmail.
- DeepSeek может менять разметку и эндпоинты, поэтому распознавание лимитов и
  автоперенос — эвристика. Если статус определился неверно, сбросьте его из меню карточки.
- 429 — это временное ограничение, а не обязательно исчерпанная дневная квота.
- Не запускайте два экземпляра одновременно: они используют одни и те же профили
  (встроена блокировка второго запуска).
- Сайт может требовать капчу/вход при первом открытии каждой сессии — это нормально,
  профиль сохранит вход.
- Сборки не подписаны; при распространении своего установщика подпишите его
  сертификатом code signing, чтобы у пользователей не появлялось предупреждение SmartScreen.

## English

BigSeek Desktop is a Windows desktop shell for chat.deepseek.com built with PyQt6.
Every session is a fully isolated Chromium profile (separate cookies, storage and cache),
so you can stay signed in to several accounts at once. It adds an AMOLED UI, a resizable
and collapsible session sidebar, per-session downloads, context-size warnings based on
token estimates, a manual and automatic token-counter reset, automatic limit/reset
detection, and one-click context transfer between sessions (the app asks the old chat
for a summary and sends it to a fresh chat in the chosen session).

Downloads: see **Releases** (`setup.exe` installer or portable ZIP).
Build from source: `pip install -r requirements.txt` then `run.bat`.
Full release build: `release.bat` (requires Python and optionally Inno Setup).
